# Vestia Website

Rebuild of www.vestiamediation.co.uk outside Wix.

- `/brand` — official logo files and brand guidelines (BRAND.md). Use these
  logo PNGs, not versions scraped from the old site.
- `/design-reference/vestia-site.html` — approved redesign prototype: visual
  direction, copy tone, intake + booking tools, fee table, mediator profiles.
  Use it as the design direction; fetch the live site for any content it
  lacks (mediator headshots, Insights article text, policy pages).
